# 🚀 Virtualized Data Table - Nuxt 3 + Element Plus + Tailwind

This project is a Nuxt 3-based frontend application implementing a performant, feature-rich data table using **Element Plus's `el-table-v2`** (virtualized list) combined with **Tailwind CSS** for styling.

## 🔧 Features

- ✅ Virtualized table rendering for large datasets using `el-table-v2`
- 🔍 Search by name or NORAD ID
- 🎯 Column sorting (ascending / descending)
- 🎛️ Custom filters via a modular `<BaseFilter />` component
- ✅ Row selection with limit enforcement
- 📦 Pagination-ready architecture
- 🧭 Navigation to detail/list page on row selection
- 🌙 Fully responsive

---

## 🛠 Tech Stack

- [Nuxt 3](https://nuxt.com)
- [Element Plus](https://element-plus.org/) (via `el-table-v2`)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
